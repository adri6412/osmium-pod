Osmium Pod for the FiiO M3K

Install Rockbox with the Osmium Sound interface from your browser, straight into the player: bootloader, firmware and system go to its internal memory, replacing the FiiO firmware. The microSD card is only for your music.

Looking for the latest release…

This page needs Chrome, Edge or another Chromium browser on a computer: it uses WebUSB, which Firefox and Safari do not have. You can still download the package and install it by hand with jztool.
1

Put the player in USB boot mode

  1. Power the player off and unplug it.
  2. First installation? Put a microSD card in the player: the installer saves a backup of the FiiO firmware on it.
  3. Hold Volume Down and plug the USB cable into the computer. The screen stays black: that is the X1000's USB boot mode.
The player does not show up in step 2
  • Windows: the USB boot device needs the WinUSB driver. Start Zadig with the player in USB boot mode, pick the device with ID A108 1000 and install WinUSB. This is needed once.
  • Linux: allow access to the device with a udev rule, then unplug and plug the player again: 
    echo 'SUBSYSTEM=="usb", ATTRS{idVendor}=="a108", ATTRS{idProduct}=="1000", TAG+="uaccess"' | sudo tee /etc/udev/rules.d/70-ingenic-usbboot.rules
sudo udevadm control --reload
  • macOS: no setup is needed.
  • Use a data cable, and try another USB port if nothing appears.
2

Install

The page downloads the release and sends it to the player with the installer; pick Ingenic USB Boot Device when the browser asks. It works for the first installation and for updates: settings and library are kept.

On the player

      
The player shows each step and restarts by itself into Osmium Pod. The
        first time, saving the backup takes a few minutes: leave it plugged in.
        Then copy your music to the card, in a card reader or by connecting the
        player to the computer.

      
The settings and the library live in the player's internal storage. When
        Rockbox runs, the computer sees only the card. To see the internal storage,
        power the player on holding Volume +, choose USB:
        internal storage, then plug the cable in.

      
If something stops the installation, the player shows the reason; you can
        unplug it, go back to step 1 and try again.

Other ways

      

        Update by copying to the card
        
With Osmium Pod already installed, a release copied to the card is taken
          at the next start. Put the card in a card reader (or connect the player while
          it runs) and choose the root of the card.

        

          
          or download the zip
        

        
        

      

      

        Recovery tools (rescue)
        
Load the installer into RAM without installing anything, to reach the
          full recovery menu: Volume +/− move, Play
          selects. It can restore fiiom3k-boot.bin, install a
          bootloader.m3k from the card, save backups and dump the flash.
          You can also pick another bootloader file, for example the official one
          from download.rockbox.org.

        
        

          
        

        

        

      

      

        If something goes wrong
        
USB boot mode is in the chip's ROM, so it is always there: the player can
          always be brought back. Run the installation again, or use the recovery
          menu above. The backup of the FiiO firmware is on the card:
          fiiom3k-boot.bin and flash.img; keep them on
          your computer.
