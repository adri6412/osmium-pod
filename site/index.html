Osmium Pod for the FiiO M3K

Install Rockbox with the Osmium Sound interface from your browser. Rockbox goes into the player's internal flash, replacing the FiiO firmware. The microSD card still holds the codecs, the settings and your music.

Looking for the latest release…

This page needs Chrome, Edge or another Chromium browser on a computer: it uses WebUSB and folder access, which Firefox and Safari do not have. You can still download the package and install it by hand with jztool.
1

Prepare the microSD card

Put the card in a card reader (or connect the player while Rockbox runs, in USB mode) and choose the root of the card. The page copies the .rockbox folder and bootloader.m3k to it; settings, database and music are kept.

or download the zip

Start the installer on the player

Put the card back in the player. Then:

  1. Power the player off and unplug it.
  2. Hold Volume Down and plug the USB cable into the computer. The screen stays black: that is the X1000's USB boot mode.
  3. Press the button below and pick Ingenic USB Boot Device.

If something goes wrong

      
USB boot mode is in the chip's ROM, so it is always there. If the player
        shows a black screen, go back to step 2 and load a bootloader. Then, from the
        recovery menu, use Bootloader → Restore to put back
        fiiom3k-boot.bin, or Install or update with the
        official bootloader.m3k on the card. The official bootloader
        starts Rockbox from the card.
